# Battleship

A browser-based Battleship game built with JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## About

This project is a playable implementation of the classic Battleship game. The player competes against a computer opponent, placing ships on a gameboard and taking turns attacking coordinates to sink the opposing fleet.

The project focuses on practicing JavaScript classes, object-oriented programming, modular code, DOM manipulation, event listeners, and unit testing.

## Features

- Play Battleship against a computer opponent.
- Place ships on your gameboard using coordinates and orientation.
- Validate ship placements to prevent overlaps and ships extending beyond the board.
- Track hits, misses, and previous attacks.
- Computer opponent randomly places ships and makes attacks without repeating shots.
- Detect when a player has sunk the opponent's entire fleet.
- Start a new game.

## How to Play

1. Place your ships on your gameboard using the available coordinate and orientation controls.
2. Start the game when your fleet is ready.
3. Click a square on the opponent's board to attack that coordinate.
4. Hits and misses are displayed on the board.
5. Take turns attacking until one fleet has been completely sunk.
6. Start a new game to play again.
